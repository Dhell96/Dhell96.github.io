How I work

Rigour is a feature,

01

Start with the system. Build a model of the physical, physiological or operational context before choosing an architecture.

02

Stress-test generalisation. Prefer subject-wise and cross-database validation over optimistic random splits.

03

Make uncertainty useful. Treat failure modes, bias and missing information as findings that guide the next model.
